# Farm Plant Explorer

A small Kivy desktop learning project that retrieves plant information from the OpenFarm API. Despite the original filename, this is an API-powered plant lookup interface rather than a conversational AI chatbot.

## Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python chatbot.py
```

The application validates empty input and handles network, HTTP, and invalid-response failures without crashing.

## Portfolio note

This repository is kept as a learning project and is not intended to be one of the three pinned portfolio projects. It demonstrates Python API integration and a Kivy user interface.
